# 🎮 PUBG Weapons Performance Dashboard

## 📊 Project Overview

This project analyzes weapon performance in PUBG using an interactive Power BI dashboard.
The goal is to compare weapons based on damage, DPS (Damage per Second), bullet speed, and efficiency.

---

## 🛠 Tools & Technologies

* Power BI
* Data Cleaning & Data Visualization

---

## 📁 Dataset

The dataset contains information about **44 weapons**, including:

* Weapon Type
* Damage
* DPS (Damage per Second)
* Bullet Speed
* Shots to Kill

---

## 📌 Key Features

* Overview of total weapons
* Average KPIs (Damage, DPS, Bullet Speed)
* Top 5 weapons comparison
* Interactive filters:

  * Weapon Type
  * Weapon Name
  * Fire Mode
  * Range

---

## 📈 Business Insights

* The dataset includes **44 weapons**, enabling a broad comparison across categories.

* The **maximum bullet speed** reaches **990**, highlighting weapons suitable for long-range combat.

* The **average damage** across all weapons is **63.34**, while the **average DPS** is **1.08K**, indicating overall performance balance.

* **Shotguns** have the **highest average damage**, making them highly effective in close-range situations.

* The **Vector** delivers the **highest DPS**, meaning it can deal damage very rapidly over time.

* However, **higher DPS does not always mean better performance**:

  * The **Win94** requires **fewer shots to kill**
  * It also has a **higher bullet speed** than the Vector
    ➝ making it more efficient and accurate in certain scenarios.

---

## 🎯 Key Takeaway

High DPS does not necessarily mean a weapon is more efficient, as factors like bullet speed and shots-to-kill significantly impact performance.
